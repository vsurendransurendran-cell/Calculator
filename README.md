CodeAlpha Calculator Project

A responsive calculator built with HTML, CSS, and vanilla JavaScript for the CodeAlpha Frontend Development task.

Features

Addition, subtraction, multiplication, division, and modulo
Clear-all, delete-last-digit, decimal, and sign-toggle controls
Keyboard support: numbers, +, -, *, /, %, ., Enter, Backspace, and Escape
Responsive layout for desktop and mobile
Accessible button labels and live display updates
Handles division by zero without showing NaN or Infinity


Project files
index.html — page structure and calculator buttons
style.css — responsive visual design
script.js — calculator logic and keyboard controls
